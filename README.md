# 💼 Portfólio com Agendamento via Redes Sociais

Este projeto é um site de portfólio desenvolvido para apresentar os trabalhos de uma cliente e facilitar o contato para agendamentos de forma simples e direta.

## 📌 Objetivo

Criar uma página moderna, responsiva e visualmente atrativa, focada em:

- Exibição de serviços e trabalhos realizados
- Fortalecimento da presença online
- Facilidade no agendamento via redes sociais

## 🚀 Funcionalidades

- 📷 Galeria de trabalhos realizados
- 📄 Apresentação dos serviços oferecidos
- 📱 Botões diretos para contato
- 🔗 Redirecionamento para agendamento via:
  - WhatsApp
  - Instagram
- 💻 Design responsivo (adaptado para celular e desktop)

## 🛠️ Tecnologias Utilizadas

- HTML5  
- CSS3  
- JavaScript  

> ⚠️ Observação: Este projeto é totalmente estático, ou seja, não possui lógica de backend ou sistema interno de agendamento. Toda a interação de agendamento ocorre via redirecionamento externo.

## 📲 Como Funciona o Agendamento

O usuário, ao navegar pelo site, pode clicar nos botões de contato que irão:

- Abrir uma conversa no WhatsApp com mensagem pré-definida  
- Redirecionar para o perfil do Instagram da cliente  

Isso elimina a necessidade de sistemas complexos e mantém o processo direto.
